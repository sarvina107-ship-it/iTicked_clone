# 🎫 iTicket.uz Telegram Bot Clone

Полнофункциональный клон официального Telegram-бота **iTicket.uz** на **Node.js (Telegraf + Express + QRCode)** для бронирования и покупки билетов на концерты, спектакли, спортивные матчи и фестивали в Узбекистане с генерацией электронных QR-билетов и панелью администратора.

---

## ✨ Возможности бота

- 🌐 **Двуязычный интерфейс:** Полная поддержка **Русского** и **Узбекского** языков (O'zbekcha / Русский) с возможностью смены языка в любой момент.
- 📂 **Категории мероприятий:**
  - 🎤 Концерты (Jah Khalib, Хамдам Собиров и др.)
  - 🎭 Театры и Балет (ГАБТ им. Навои)
  - ⚽️ Спорт (Матчи Суперлиги, «Пахтакор» и др.)
  - 👶 Детям и Семье (Цирк, шоу)
  - 🎪 Фестивали и Шоу (Magic City Fest)
- 🎟 **Интерактивный выбор мест:**
  - Выбор сектора (VIP, Партер, Трибуна, Амфитеатр, Балкон) с актуальными ценами в сумах.
  - Выбор количества билетов (1, 2, 3, 4, 5, 6 шт.).
- 📱 **Оформление заказа:**
  - Ввод ФИО.
  - Отправка номера телефона через кнопку Telegram (`Send Contact`) или ввод вручную.
  - Выбор метода оплаты (Click, Payme, Оплата в кассе).
- 📲 **Генерация электронного QR-билета:**
  - Создание уникального номера билета (`#TK-XXXXXX`).
  - Генерация настоящего графического QR-кода высокого разрешения для прохода на мероприятие.
- 🎟 **Личный кабинет «Мои билеты»:**
  - Просмотр всех купленных билетов и сохраненных QR-кодов в любое время.
- 🔍 **Поиск:**
  - Быстрый поиск по названию события, артисту или площадке (Humo Arena, Дворец Дружбы Народов и др.).
- 👑 **Панель Администратора (`/admin`):**
  - Моментальные push-уведомления администратору в Telegram при каждой покупке билета со всеми контактами клиента.
  - 📊 Статистика: количество пользователей, заказов и сумма продаж.
  - 📋 Просмотр последних заказов.
  - 📢 Рассылка сообщений всем пользователям бота.
- 🌐 **Express HTTP сервер:** Встроенный веб-сервер для прохождения проверок (Health checks) на Render.com, Railway, Heroku и других облачных платформах.

## 🚀 Локальный запуск

1. Склонируйте или откройте проект в терминале:
   ```bash
   cd botiTicked
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Проверьте файл `.env`:
   ```env
   BOT_TOKEN=8722077893:AAE5Uqawm_UW-R0iZWRXxwe58SrsP4KuiQ4
   ADMIN_ID=1633967629
   PORT=3000
   ```

4. Запустите бота:
   ```bash
   npm start
   ```

## ☁️ Пошаговая инструкция: Деплой на Render (Работает 24/7 глобально)

[Render.com](https://render.com) — отличная платформа для бесплатного хостинга Node.js проектов.

### Шаг 1. Загрузите проект на GitHub
1. Если проект еще не в Git, инициализируйте репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Initial commit - iTicket Telegram Bot"
   ```
2. Создайте новый репозиторий на [GitHub](https://github.com/new) (например, `iticket-telegram-bot`).
3. Привяжите и отправьте код:
   ```bash
   git remote add origin https://github.com/ВАШ_ЛОГИН/iticket-telegram-bot.git
   git branch -M main
   git push -u origin main
   ```

---

### Шаг 2. Создайте сервис на Render
1. Зарегистрируйтесь или войдите на [render.com](https://render.com) через ваш GitHub.
2. В панели управления Render нажмите **New +** в правом верхнем углу.
3. Выберите **Web Service** (или **Background Worker**).
   > 💡 Рекомендуется **Web Service** (он абсолютно бесплатный).
4. Выберите репозиторий с ботом из вашего списка GitHub и нажмите **Connect**.

---

### Шаг 3. Настройка параметров сервиса в Render
Заполните поля:
- **Name**: `iticket-bot` (любое удобное имя)
- **Region**: Frankfurt (EU) или Сингапур (выбирайте ближе к вам)
- **Branch**: `main`
- **Root Directory**: оставьте пустым
- **Runtime**: `Node`
- **Build Command**: `npm install`
- **Start Command**: `npm start`
- **Instance Type**: `Free`

---

### Шаг 4. Установка переменных окружения (Environment Variables)
Прокрутите вниз до раздела **Environment Variables** (Переменные окружения) и добавьте:

| Key (Ключ) | Value (Значение) |
|---|---|
| `BOT_TOKEN` | `8722077893:AAE5Uqawm_UW-R0iZWRXxwe58SrsP4KuiQ4` |
| `ADMIN_ID` | `1633967629` |
| `NODE_VERSION` | `20` (или `22`) |

> ℹ️ Переменную `PORT` задавать вручную не требуется — Render автоматически назначит ее, а наш Express-сервер автоматически ее подхватит (`process.env.PORT`).

Нажмите **Create Web Service**.

---

### Шаг 5. Проверка запуска
1. Render начнет сборку (`npm install`) и выполнит `npm start`.
2. В логах вы увидите:
   ```
   🌐 Web server is running on port 10000
   🤖 iTicket.uz Telegram Bot successfully started!
   👑 Admin ID: 1633967629
   ```
3. Статус сервиса станет зеленым: **Live**.
4. Откройте вашего бота в Telegram: [@booking_iTicked_clone_bot](https://t.me/booking_iTicked_clone_bot), нажмите `/start` и протестируйте покупку билетов!

### 💡 Лайфхак: Как сделать так, чтобы бесплатный Render не засыпал (24/7)
Бесплатный тариф Render Web Service «засыпает» при отсутствии входящих HTTP-запросов более 15 минут.
Чтобы бот работал **24/7 без пауз**:
1. Скопируйте ссылку вашего сервиса на Render (например, `https://iticket-bot-xxxx.onrender.com`).
2. Зайдите на бесплатный сервис мониторинга [uptimerobot.com](https://uptimerobot.com) или [cron-job.org](https://cron-job.org).
3. Добавьте новый HTTP-монитор с интервалом проверки каждые **5-10 минут** на адрес вашей ссылки (например, `https://iticket-bot-xxxx.onrender.com/health`).
4. UptimeRobot будет автоматически пинговать сервер, и Render **никогда не уснет**, оставаясь активным 24 часа в сутки!
